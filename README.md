# HLH Banners (v1.0)

Custom Shaders Patch (CSP) Lua app for Assetto Corsa that renders animated race-control capsules (flags, cautions, penalties, give-back notices, and VSC delta) in movable, frameless on-screen windows.

## Features

- **Animated capsules:** Smooth opening and closing animations with icon badge bounce and text panel reveal.
- **Movable windows:** Separate independently movable windows for flags, urgent alerts, race info, and VSC delta. A closed group window automatically falls back to showing in the main banners window.
- **Frameless design:** Seamless native integration utilizing official CSP window flags (`NO_BACKGROUND`, `NO_TITLE_BAR`, `AUTO_RESIZE`).
- **Crisp typography:** Pre-rendered letter atlas for immediate, tear-free text animations.
- **Audio alerts:** Radio chime notification on new banners with configurable volume.
- **Delta window:** F1-style VSC delta telemetry bar with sector strikes, timing delta, and live status hints.
- **Multilingual:** Supports Spanish and English, selectable via in-game settings.

## Installation (Content Manager)

1. Download `HLH-Banners-v1.0.zip` from the Releases page.
2. Drag and drop the `.zip` file directly into **Content Manager**.
3. Click the hamburger menu (three horizontal lines) in the top-right corner of Content Manager and click **Install**.
4. In Content Manager, navigate to `Settings -> Assetto Corsa -> Apps` and ensure **HLH Banners** is enabled.
5. In game, open the right-side apps bar and activate **HLH Banners**.

## Requirements

- Assetto Corsa
- Custom Shaders Patch (CSP) v0.2.0 or newer (v0.3.0+ recommended)
